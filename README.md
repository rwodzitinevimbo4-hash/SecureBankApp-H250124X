# Secure Banking Application

## Description
This project is a Java-based banking application designed to simulate secure account management in a console environment. It allows users to register, log in, create accounts, and perform financial transactions while maintaining data persistence and security.

## Features
- User registration and login system
- Password hashing using a salt and PBKDF2 for secure storage
- Account lockout after repeated failed login attempts
- Creation of Savings and Current accounts
- Deposit and withdrawal functionality with validation
- Transaction history tracking for each account
- Storage of data in local text files for persistence
- Input validation and restrictions to protect against invalid data

## How to Run
1. Open the project in a Java IDE or terminal.
2. Compile the source files.
3. Run the main class to start the banking application.

## Project Summary
This application demonstrates core Java programming concepts, object-oriented design, and practical security practices for a simple banking system.
